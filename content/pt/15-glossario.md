# Glossário e perguntas frequentes

## Glossário

| Termo | Significado |
|---|---|
| **Condicional** | Sacola de peças enviada para a cliente experimentar e pagar só o que ficar. |
| **Sacola** | Sinônimo de condicional nas telas do celular. |
| **Por quantidade** | Modo em que só se registra quantas peças foram e o valor final informado. |
| **Peça por peça** | Modo em que cada peça tem nome, tamanho e preço; o valor final é calculado. |
| **Escolha** | O que a cliente disse que vai ficar. Não fecha a venda. |
| **Conferência** | O que a loja confirma, com as peças na mão, que foi vendido. |
| **Valor enviado** | Soma das peças que saíram (quando os preços são conhecidos). |
| **Valor final** | O que a cliente deve pelas peças vendidas. |
| **A receber** | Valor final menos pagamentos. |
| **Prazo vencido** | Com a cliente e depois da data de devolução. |
| **Não recebido** | Tentativa de entrega sem sucesso. |
| **Justificativa** | Texto obrigatório para finalizar com saldo em aberto. |

## Perguntas frequentes

**A cliente precisa criar conta?**
Não. A cliente escolhe as peças por um link enviado no WhatsApp, sem conta nem senha. Veja [Entregas, coletas e página da cliente](#pt-entregas).

**O sistema cobra a cliente?**
Não. Ele só registra pagamentos recebidos pelos meios da loja.

**Funciona no celular?**
Sim, foi pensado primeiro para o celular: barra inferior, botões grandes e cadastro rápido.

**Dá para usar em mais de uma loja?**
O banco já separa os dados por loja. A tela de troca de loja será feita quando houver uma segunda loja.

**O mapa mostra os endereços para alguém de fora?**
Não. O mapa só existe dentro da área da loja, depois do login.
