# CondicionalMap — documentação

Texto da documentação do [CondicionalMap](https://condicionalmap.netlify.app), um sistema para lojas de roupa gerenciarem condicionais (escolha da cliente por link, entrega com código de confirmação e mapa das sacolas).

Publicada em: **https://condicionalmap.netlify.app/docs/**

## Como gerar

```bash
npm install
npm run build      # gera dist/index.html (página única, com busca e diagramas)
```

O conteúdo fica em `content/pt/*.md`. Cada arquivo tem um cabeçalho com `slug`, `title`, `group` e `description`.

O código do sistema está em um repositório privado.
